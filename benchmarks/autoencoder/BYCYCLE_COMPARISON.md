# Experiment B: independent cycle-based comparison
This is an exploratory extension using the existing 600 training and 200 development-validation recordings. No final test data, no changes to FeatureGraph construction, no autoencoder retraining.

Bycycle 1.2.0 compute_shape_features, peak-centered cycles, fixed band 0.15–0.45 Hz (covers the known development simulation frequency range), 8-second extrema-localization FIR filter (shorter than the default three cycles of the lower cutoff to accommodate 20-second records). No burst screening: both methods use complete detected cycles whose peaks fall in the central 10 seconds. These are fixed pilot settings, not a demonstrated optimum. No per-record target frequency is provided. The methods receive identical 1000-sample raw waveforms.

Bycycle uses native trough-to-trough period in seconds, half its mean rise/decay excursion as amplitude, trough-to-peak rise duration in samples, and 1-abs(2*time_rdsym-1) for symmetry. FeatureGraph retains peak-to-peak period, half raw range, rising sample count, and its original symmetry. These are analogous, not identical measurements. Both use four means or eight means in two time bins. Train-only median imputation and standardization; Ridge alpha=1 and Random Forest 200 trees, seed 0, as in Experiment B. Report coverage, counts, predictions, R²/MAE/RMSE, coefficients and amplitude ablation. Paired complete-case sensitivity uses the intersection of complete records in both training and validation. No claims of method superiority before results. Unexpected library errors fail the run instead of silently excluding records.

The matched-pair extension is deferred until this primary comparison is verified. The existing matched pairs were constructed to equalize FeatureGraph's later measured amplitude, which does not ensure equality for bycycle. A method-specific matched design or separately defined common envelope control is required. Compare to existing autoencoder results only after checking FG reference reproduction and dependency versions. No cross-domain claim follows from this pilot.
